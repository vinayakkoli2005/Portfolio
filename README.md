# Vinayak Koli - Portfolio Website

A professional, minimal, and dark-aesthetic personal portfolio website for Vinayak Koli.

## Overview

This portfolio website is designed to showcase my skills, projects, and work experience as an Aspiring Software Engineer and Backend Developer at IIIT Delhi. It features a responsive grid layout, clean typography, and subtle fade-in animations on scroll.

**Live Demo Preview (Local Setup):** Open `index.html` in your web browser.

## Features

- **Dark Aesthetic UI:** A clean, modern design featuring a dark background (`#0D0D0D`) with striking deep red (`#8B0000`) accents.
- **Fully Responsive Layout:** Built seamlessly with CSS Grid and Flexbox to ensure perfect display on desktops, tablets, and mobile devices.
- **Scroll Animations:** Integrated an `IntersectionObserver` to trigger subtle and non-intrusive fade-in animations as the user scrolls.
- **Semantic HTML5:** Structurally sound and accessible markup.
- **Direct Asset Integration:** Connects dynamically with local image assets (`hero-mountain.png` and `ninja-horse.png`) and my official resume (`Vinayak koli resume.pdf`).

## Tech Stack

The core foundation relies entirely on vanilla web technologies for a lightweight, fast, and optimized experience:

- **HTML5:** Semantic structure and content.
- **CSS3:** Custom Variables, Flexbox, Grid Layout, and pure CSS animations without needing an external library.
- **Vanilla JavaScript:** Powers the `IntersectionObserver` scroll animations logic natively in the browser.
- **Google Fonts:** The modern, legible `Inter` font is used heavily for professional typography.

## Key Sections

1. **Hero Header:** Bold visual introduction with my primary tech focus and quick call-to-action buttons.
2. **About Me:** Brief professional summary bridging my education and backend internship experience.
3. **Technical Skills:** A categorized grid displaying proficiency across Languages, Tools, and Core CS Coursework (Java, React Native, Laravel, FastAPI, etc.).
4. **Projects:** Highlighting key GitHub repositories ranging from Cross-Platform mobile apps evaluating AI models to full-fledged OOP backend simulations.
5. **Experience & Education:** A scalable vertical timeline detailing professional progression.
6. **Contact Section:** Working links to my official GitHub, LinkedIn, and Email for networking.

## Local Setup

To run or modify the website locally:

1. Clone or download this project folder physically to your local machine.
2. Ensure the following assets are present in the exact root folder of `index.html`:
   - `hero-mountain.png`
   - `ninja-horse.png`
   - `style.css`
   - `script.js`
   - `Vinayak koli resume.pdf`
3. Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Safari, Firefox). No build step, node package, or terminal server is strictly required!
